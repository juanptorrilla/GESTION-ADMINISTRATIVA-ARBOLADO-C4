# Gestión Administrativa – Arbolado Comuna 4

Aplicación Android independiente para la gestión administrativa del arbolado de la Comuna 4. Integra el módulo de Relevamiento V7 y accesos a las planillas, mapas y tableros de trabajo.

## Generación del APK

El flujo **Generar APK Android** se ejecuta automáticamente al actualizar `main` o puede iniciarse manualmente desde GitHub Actions. El APK se publica como artefacto `gestion-administrativa-arbolado-c4-apk`.

El módulo Relevamiento se basa en la rama `autoria-v7` del repositorio original. Este proyecto es independiente y no modifica el repositorio fuente ni sus planillas.
